# v1.30.0 — 自动注入 Wikilink(Graph 救星)

> **代号**: `auto-wikilinks` · 2026-09-04

## 🐛 问题

vault 笔记正文里**没有 `[[wikilink]]` 标记**(从 Obsidian 迁移过来时历史缺失)→ graph-view 没节点、wikilink 跳转失效。

## ✅ 修复

### 1. `src/services/auto-wikilinks.ts` — 自动注入引擎

```ts
const result = await autoInjectWikilinks({ dryRun: true });
// { added: 0, candidates: [...], skipped: 0 }
```

**算法**:
1. 遍历所有 vault 笔记
2. 对每篇 A,扫所有目标 B 的标题,提取 keywords(去路径/日期/序号)
3. 在 A 的正文里**没**有 `[[B]]` 但**提到** B 的核心词 → 候选
4. 找到第一次出现位置,**不在**已有的 `[[...]]` 内部
5. dryRun 模式只统计不写

### 2. graph-view 顶部加 3 个按钮

- 🔍 **预览链接** — dryRun 模式,显示"将注入 N 条到 M 篇"
- ✨ **自动建立链接** — 真正写入 + 重建图谱
- 🔄 **重建图谱** — 仅重建(不动笔记)

### 3. 自动 chunker 重切

注入链接后,自动触发对应笔记的 chunker 重切(让 graph 节点立即可见)。

## ⚠️ 注意事项

- **本地文件(📕📘)默认跳过** — 不污染 PDF/EPUB 自动生成的 md
- **frontmatter 区域不注入** — 保护 yaml 不被破坏
- **每篇最多 20 条** — 防止链接爆炸
- **回滚困难** — 当前没有"标记注入"机制,撤销只能手动 sed
