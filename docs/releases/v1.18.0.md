## ✨ 新增

### `src/components/graph-view.ts`

**数据流**:
1. 遍历 Dexie notes 提取 `[[wikilink]]`
2. 解析为边(`from → to`)+ 反链数统计
3. 节点 = vault 里所有 path(最多 200,按反链数排序补足)
4. 颜色按**顶层目录**分组(最多 10 种)
5. 布局:**简化力导向**(按 group 圆形分布 + 组内节点均匀排)

**渲染**:
- **纯 SVG**(不引入 vis-network 之类大依赖)
- 节点:圆 + 标签(>18 字截断)
- 边:折线 + 箭头 + 粗细按引用次数
- 颜色:10 种 GROUP_COLORS 按目录轮换
- hover:tooltip 显示完整 path + 反链数 + 目录
- click → `open-note` 事件 → 父组件打开笔记

### 工具栏加 🕸 按钮

`main.ts` 工具栏新增 `🕸` 按钮 → 弹出全屏图谱 modal。
