# v1.20.0 — Phase A.2: 多笔记上下文(批量提问)

> **代号**: `multi-note-ctx` · 2026-09-04

## ✨ 新增

### 把"当前打开的笔记"自动注入 chat 上下文

- chat-panel 加 `@property currentNotePath: string`
- main.ts 渲染时传入 `this.currentNote?.path`
- 每次发送时,chat-panel 把当前笔记的 **前 5 个 chunk** 拼进 `kbCitations` 最前(score = 1.0,最高优先级)

### 行为

- 切换笔记 → 自动切换上下文
- 关闭笔记(currentNotePath = '') → 不附加
- LLM 会"知道"用户当前在读什么,回答更聚焦

### 与 KB 检索的关系

```
注入顺序: 当前笔记 chunks (score=1.0) → KB 检索 topN
```

LLM 会优先引用"当前笔记"的内容,把它当成"对话焦点"。
