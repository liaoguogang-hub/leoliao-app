## 🐛 问题

- **EPUB 只索引 10 chunks**:之前 v1.26.0 chunker paragraph-only 没生效? 或者 EPUB spine 解析只成功一小部分?
- **PDF 只索引目录+封面**:正文页 PDF.js 文字提取拿不到

## ✅ 修复

### 1. PDF 每页诊断日志

```ts
if (i <= 10 || i % Math.floor(idxMax / 10) === 0) {
  console.log(`[file-opener] PDF p${i}/${idxMax}: items=${items.length}, text.length=${pageText.length}`);
}
```

### 2. EPUB 章节空文本诊断

```ts
if (!text) {
  console.log(`[file-opener] EPUB 章节空文本: ${zipPath} (title="${title}", xhtml.length=${xhtml.length})`);
  chaptersEmpty++;
  continue;
}
```

### 3. EPUB fallback

如果 spine 模式下 `chaptersIndexed < totalSpine * 0.5`,启动 fallback 扫所有 xhtml:

```ts
// 找所有 xhtml/html,跳过 nav/toc,补提取
if (chaptersIndexed < totalSpine * 0.5 && allFileObjs.length > totalSpine) {
  console.warn('[file-opener] EPUB spine 解析不够,启动 fallback 扫所有 xhtml');
  for (const obj of allFileObjs) {
    if (!/\.(x?html?)$/.test(obj.decoded.toLowerCase())) continue;
    if (/nav|toc/.test(obj.decoded.toLowerCase())) continue;
    // 提取 + 追加
  }
}
```
