## ✨ 新增

### 1. LRU 缓存层

```ts
// 新增导出
export function getCacheStats(): CacheStats;
export function clearRerankCache(): void;
```

**配置**:
- `CACHE_MAX_SIZE = 100`(最多 100 条)
- `CACHE_TTL_MS = 30 * 60 * 1000`(30 分钟过期)

**缓存 key**:`hash(query + 结果指纹 + opts 指纹)`
- query 原文
- 结果指纹:`path#idx:snippet.length` × 前 50 条
- opts 指纹:`topN / timeoutMs / forceFallback / normalize`

**LRU 策略**:Map 保持插入顺序,溢出时驱逐最旧条目;命中时删了重插刷新"最近使用"位置。

**TTL 策略**:30 分钟未访问自动失效(适合"用户反复问相似问题"的场景)。

### 2. 权重常量集中

把 v1.12.0 散在 `bm25RescoreOne` 里的魔数提到顶部常量:

```ts
export const RERANK_WEIGHTS = {
  titleHit: 3.0,             // 标题命中加权
  headingHit: 2.0,           // heading 命中加权
  contentTf: 1.0,            // chunk 内容 BM25 TF 加权
  phraseBonus: 1.5,          // 连续短语命中加成
  shortChunkPenalty: 0.8,    // 太短的 chunk 降权
  shortChunkThreshold: 50,   // "太短"字数阈值
} as const;
```

**调优点**:改这个对象一处,全文件生效,无需找散落魔数。

### 3. `RerankOptions.skipCache`

新增可选字段,默认 `false`(用缓存)。**UI 调试**时设 `true` 可强制重算:

```ts
await rerank(query, results, { skipCache: true });  // 不读不写缓存
```

### 4. `CacheStats` 命中率统计

```ts
interface CacheStats {
  size: number;          // 当前缓存条数
  hits: number;          // 累计命中次数
  misses: number;        // 累计未命中次数
  hitRate: number;       // 命中率 0-1
  evictions: number;     // 累计 LRU 驱逐次数
}
```
