# v1.22.0 — Phase X.1: 导出能力扩展

> **代号**: `export-conv` · 2026-09-04

## ✨ 新增(`src/services/export-extra.ts`)

### 1. `exportConversation(sessionId)`
- 导出整个 chat session 为 Markdown
- 包含消息角色图标 + 时间戳 + 原始内容

### 2. `exportBook(prefix)`
- 把某文件夹所有笔记拼成"小书"
- 按目录分组,每篇笔记用 ``` ``` 代码块包裹原文
- 头部带目录结构和元信息

### 3. `exportJsonLd(prefix)`
- JSON-LD 格式导出,符合 schema.org 语义网标准
- 字段:`@id` (leoliao:///{path}) / `@type: Article` / `references` (wikilink 列表) / `mtime` / `size`
- 可直接喂给第三方知识图谱工具

### 4. `downloadAsFile(content, filename, mimeType)`
- 触发浏览器下载(纯前端,Blob + URL.createObjectURL)
