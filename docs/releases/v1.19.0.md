## ✨ 新增(4 个工具,默认启用)

### 1. `get_chunk(path, idx)`
- 读取指定 path + idx 的 chunk 全文
- 用于"深入理解 kb_search 已给的 chunk 上下文"
- 返回 `{ path, idx, heading, content, hash }`

### 2. `list_tags(limit?)`
- 列出 vault 内所有 frontmatter tag + 频次
- 用于"我有哪些主题可以聊"
- 返回 `Array<{ tag, count }>`

### 3. `get_history(limit?)`
- 读最近打开的笔记/本地文件
- 用于"我之前看过什么"
- 返回 `Array<{ id, type, name, path, size, openedAt }>`

### 4. `find_by_tag(tag, limit?)`
- 按 tag 名找出所有带该 tag 的笔记
- 用于"我写过哪些 V8 笔记"
- 返回 `{ tag, count, paths[] }`

### 5. `note_edit` 仍存在但**默认禁用**(太危险)
