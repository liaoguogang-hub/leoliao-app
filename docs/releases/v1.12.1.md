# v1.12.1 — Phase R.1.1: Rerank UI 接入

> **发布日期**: 2026-09-04
> **代号**: Phase R.1.1 / rerank-ui
> **类型**: 小版本(向后兼容)

---

## 🎯 主题

把 v1.12.0 引入的 Rerank 引擎**接入 chat-panel UI**——用户可以在聊天设置里开关 Rerank,调整 TopN。

---

## ✨ 新增

### 1. chat-panel 新增 Rerank 开关

设置面板中,**[检索模式]** 下拉下方新增:

```
☑ 🎯 启用 Rerank(精确化检索结果)
```

勾选后展开:
```
Rerank TopN: [10]  对 RRF 后的前 N 条做二次精排(默认 10)
```

**默认状态**:**关闭** (向后兼容 — v1.12.0 之前的行为)
**持久化**:localStorage key `ll-chat-rerank`
**作用域**:每次发送问题时生效

### 2. Agent 路径同步支持

`AgentContext` 新增 3 个字段,自动从 chat-panel 透传:

```ts
interface AgentContext {
  // ...已有字段
  searchMode?: 'bm25' | 'vector' | 'hybrid';
  useRerank?: boolean;
  rerankTopN?: number;
}
```

Agent 内的 `kb_search` 工具调用,会复用用户在 chat-panel 设置的 Rerank 开关。

## ⚠️ 升级注意

- **零破坏性** — useRerank 默认 false,行为等同 v1.12.0
- **首次启用 Rerank** — 触发 cross-encoder 模型懒加载(~25MB,可能 30s)
- **开启后 chat 会稍慢** — Rerank Level 1 约 +1.5s
