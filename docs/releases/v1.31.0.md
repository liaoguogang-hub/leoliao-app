# v1.31.0 — PDF 文字提取:全 cMap 兜底

> **代号**: `pdf-full-cmap` · 2026-09-04

## 🐛 问题

PDF 重索引后,正文页(目录后)文字提取为 0,只有目录页/封面页有内容。
- 原 27 个 cMap 中没有匹配的字体编码
- PDF 的正文用了罕见的 CID 复合字体
- PDF.js 找不到 ToUnicode CMap,无法解码

## ✅ 修复

### 1. 全量 cMap(169 个)

```bash
# 从 npm 包复制全部 cMap
cp node_modules/pdfjs-dist/cmaps/* public/cmaps/  # 169 个
cp node_modules/pdfjs-dist/cmaps/* android/.../assets/public/cmaps/  # 同步到 APK
```

### 2. 加 standardFontDataUrl

```ts
const loadingTask = pdfjsLib.getDocument({
  data: buffer,
  cMapUrl: './cmaps/',
  cMapPacked: true,
  standardFontDataUrl: './standard_fonts/',  // v1.31.0 新增
  verbosity: 0,
});
```

16 个 standard_fonts 也复制到 `public/standard_fonts/`。

## 📊 体积影响

| 项 | 之前 | 之后 |
|---|---|---|
| `public/cmaps/` | 27 个 / ~10 MB | 169 个 / ~14 MB |
| `public/standard_fonts/` | 0 | 16 个 / ~3 MB |
