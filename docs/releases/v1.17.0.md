## ✨ 新增

### 1. `generateNoteMoc(path)` — 单笔记 MOC

```ts
interface NoteMoc {
  path: string;
  backlinks: MocEntry[];  // 谁引用了我(V47 已有,这里归口)
  sameTag: MocEntry[];    // 共享至少 1 个 frontmatter tag
  parents: MocEntry[];    // 父目录的其他笔记
  downstream: MocEntry[]; // 双向引用(我引它 + 它引我)
  stats: { backlinkCount, sameTagCount, parentCount, downstreamCount };
}
```
