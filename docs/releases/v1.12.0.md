# v1.12.0 — Phase R.1: Cross-Encoder Rerank 上线

> **发布日期**: 2026-09-04
> **代号**: Phase R.1 / rerank-mvp
> **类型**: 检索增强(非破坏性)

---

## 🎯 主题

把现有"BM25 + 向量 RRF 融合"升级到"BM25 + 向量 + **Cross-encoder Rerank**"。目标:在相同召回数量下,Top-5 准确率提升。

---

## ✨ 新增

### 1. `src/lib/reranker.ts` — 三档降级 Rerank 引擎

```
Level 1: Cross-encoder  ← 理想路径(@xenova/transformers + ms-marco-MiniLM-L-6-v2)
Level 2: BM25 重打分     ← 零依赖 fallback(标题 ×3 / heading ×2 / 内容 ×1)
Level 3: Passthrough     ← 兜底返回原数组
```

**关键设计**:
- **永不抛错** — 任何环节失败都自动降级,调用方拿到的是 SearchResult[]
- **3 秒硬超时** — 模型加载 + 推理全程限时,失败不阻塞主流程
- **零额外首屏成本** — 模型按需懒加载(`Xenova/ms-marco-MiniLM-L-6-v2` 量化版 ~25MB)
- **零新增依赖** — 复用项目已有的 `@xenova/transformers`

### 2. `src/lib/search.ts` — 签名扩展

```ts
// 旧
search(query, k, maxChars, paths, mode, includeLocal?)
// 新(可选第 7 个参数)
search(query, k, maxChars, paths, mode, includeLocal?, rerankOpts?)
```

不传 `rerankOpts` 时,行为完全等同于 v1.11.x(**向后兼容**)。

## 🔧 内部实现

### 检索流水线(新)

```
┌─────────────┐   ┌─────────────┐
│  BM25       │   │  向量检索    │
│  top-50     │   │  top-50     │
└──────┬──────┘   └──────┬──────┘
       │                 │
       └────────┬────────┘
                ▼
        ┌───────────────┐
        │  RRF 融合       │
        │  100 → ~30~50  │
        └───────┬───────┘
                ▼
        ┌───────────────┐
        │  Rerank       │  ← v1.12.0 新增
        │  (可选,默认关闭)│
        └───────┬───────┘
                ▼
        ┌───────────────┐
        │  maxChars 截断 │
        └───────┬───────┘
                ▼
        SearchResult[]
```

### Rerank 评分公式(Level 2 fallback)

```
score(query, chunk) =
   3.0 × Σ[query_token in title]      // 标题命中权重最高
 + 2.0 × Σ[query_token in heading]    // heading 命中次之
 + 1.0 × Σ BM25_tf(query_token, content)  // chunk 内容 BM25 风格
 + 1.5 × [phrase_match bonus]         // 连续短语命中
 × 0.8 [if snippet.length < 50]       // 太短的 chunk 降权
```

### 性能预算

| 阶段 | 输入 | 耗时 |
|---|---|---|
| BM25 + 向量并行 | 1000+ chunks | ~50ms |
| RRF 融合 | top50 × 2 | ~1ms |
| Rerank Level 1 | 50 候选 | ~1500ms |
| Rerank Level 2 | 50 候选 | <50ms |
| **总计(含 rerank)** | | **< 2s** |
