## 🎯 主题

LLM 流式输出时,实时解析 `[KB#N]` 引用 token,在 chat 窗口右侧弹出**流式引用抽屉**,每提到一个新引用就新增一张卡片。

这是 WeKnora "chat-with-docs" 体验的灵魂:边看回答,边看到引用从右侧"飞"出来,点卡片直接跳到笔记对应 chunk。

## ✨ 新增

### 1. `liveCitations` state

```ts
@state() private liveCitations: Array<{ idx: number; result: SearchResult }> = [];
```

**生命周期**:
- 每次发送(`onSend`)开头 → `clearLiveCitations()` 清空
- 流式循环每收到 delta → `parseLiveCitations(fullText, kbCitations)` 增量更新
- 流式结束 → 保留,直到下次发送

### 2. `parseLiveCitations(fullText, kbCitations)`

```ts
private parseLiveCitations(fullText: string, kbCitations: SearchResult[]) {
  const re = /\[KB#(\d+)\]/g;
  const seen = new Set<number>();
  const next: Array<{ idx: number; result: SearchResult }> = [];
  let m;
  while ((m = re.exec(fullText)) !== null) {
    const idx = parseInt(m[1], 10);
    if (seen.has(idx)) continue;
    seen.add(idx);
    const result = kbCitations[idx - 1];
    if (result) next.push({ idx, result });
  }
  // 性能:无新增则不 setState
  if (next.length === this.liveCitations.length &&
      next.every((x, i) => x.idx === this.liveCitations[i]?.idx)) {
    return;
  }
  this.liveCitations = next;
}
```

**特性**:
- 正则匹配 `[KB#1] [KB#2] ...`
- `idx` 对应 `kbCitations[idx-1]`(RAG prompt 里 `#1` 是数组下标 0)
- **去重**(同一 idx 不重复出现)
- **性能优化**:无新增不 setState,避免每 chunk 都触发整个 drawer 重渲染

### 3. 抽屉 UI(`.citations-drawer`)

固定在屏幕右上角:

```
┌──────────────────────────────────┐
│ 📑 引用 (3)        ⏳ 流式中... │
├──────────────────────────────────┤
│ ┌──────────────────────────────┐ │
│ │ KB#1  笔记标题                │ │
│ │ 📌 heading 名                 │ │
│ │ snippet 前 100 字…           │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ KB#2  另一个笔记              │ │
│ │ ...                           │ │
│ └──────────────────────────────┘ │
│ ...                              │
└──────────────────────────────────┘
```

**特性**:
- 抽屉从右侧滑入动画(`drawer-slide-in`)
- 新增卡片从顶部飞入(`drawer-card-in`)
- 流式状态边框高亮(`accent` 色)
- "⏳ 流式中..." 文字 1.2s 呼吸动画
- 卡片可点击 → 派发 `open-citation` 事件 → 跳到对应 chunk(v1.14.0)

### 4. 与 v1.14.0 联动

点击抽屉卡片 → `open-citation` 事件 detail 带 `path + idx` → `main.ts` 触发 `ll-jump-to-chunk` → note-view 滚动到对应 chunk + 高亮 3 秒。

**完整链路**:
```
LLM 输出 "[KB#1]..." 
  → chat-panel.parseLiveCitations() 
  → liveCitations state 
  → 抽屉实时新增卡片 
  → 用户点卡片 
  → open-citation 事件 
  → main.ts.handleSelectDirect(path, idx) 
  → ll-jump-to-chunk 全局事件 
  → note-view.handleJumpToChunk 
  → scrollIntoView + highlight-flash
```
