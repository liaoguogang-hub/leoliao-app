## 🐛 问题

1. **每次打开 APK 都重新同步** — 没缓存上次同步时间,每次启动都拉 OSS manifest
2. **知识图谱构建不成功** — graph-view 模板嵌套少了闭合 `}`,导致构建分支逻辑错误/永远不结束

## ✅ 修复

### 1. 启动 5 分钟缓存跳过

`main.ts` connectedCallback:
```ts
const lastSync = parseInt(localStorage.getItem('ll-last-sync') || '0', 10);
if (lastSync && Date.now() - lastSync < 5 * 60 * 1000) {
  // 从 IndexedDB 读缓存,秒开
  const cached = await loadManifest();
  if (cached.length > 0) { ...ready... }
}
```

### 2. Graph render 重构

把多层嵌套模板 `${a ? html``...`` : b ? html``...`` : html``...``}` 拆成:
- `render()` 薄壳
- `renderBody()` 按 loading/nodes 状态分发
- 每层单独返回,消除反引号嵌套错误
