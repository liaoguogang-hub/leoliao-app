> **发布日期**: 2026-09-04

> **类型**: 用户体验升级(向后兼容)

---

## 🎯 主题

点 chat 引用 / 搜索结果 → **自动跳到笔记内对应 chunk 段落** + **黄色高亮 3 秒**。

这是 WeKnora 体验里最被用户感知的一个特性 —— 回答里点 `[KB#1]`,直接看到原笔记里那一段在闪。

---

## ✨ 新增

### 1. 渲染时插 chunk 锚点

`renderer.ts` 新增 `ParseNoteOptions`:
```ts
interface ParseNoteOptions {
  chunks?: Array<{ idx: number; startOffset: number; endOffset: number }>;
  path?: string;
}
```

调用方(`sync.ts` 的 `getNote`)传入 chunks 信息,渲染时按段落边界轮流插锚点:

```html
<a id="cid-0" class="cid-anchor" data-cid="0" data-path="01.公众号/foo.md"></a>
<p>这是第一段...</p>
<a id="cid-1" class="cid-anchor" data-cid="1" data-path="01.公众号/foo.md"></a>
<h2>二级标题</h2>
<p>第二段...</p>
```

**位置策略**:按 HTML 段落边界拆(`</h2></p></ul></ol></pre>` 等),每个段前轮流分配 chunk idx。粗粒度但够用。

### 2. note-view 监听 jump-to-chunk 事件

```ts
// 全局事件名:ll-jump-to-chunk
// detail: { path: string; idx: number }
document.addEventListener('ll-jump-to-chunk', this.handleJumpToChunk);
```

处理流程:
1. 校验 path 是否匹配当前笔记(否则忽略)
2. 等渲染稳定(`updateComplete.then`)
3. 找 `a.cid-anchor[data-cid="${idx}"]` 元素
4. `scrollIntoView({ behavior: 'smooth', block: 'start' })`
5. 加 `.highlight-flash` class(3 秒后自动移除)

### 3. 黄色高亮 3 秒动画

CSS:
```css
.cid-anchor.highlight-flash {
  visibility: visible;
  pointer-events: none;
  animation: cid-flash 3s ease-out;
}
@keyframes cid-flash {
  0% { background: rgba(255, 220, 0, 0.7); box-shadow: 0 0 12px rgba(255, 220, 0, 0.8); }
  20% { background: rgba(255, 220, 0, 0.5); }
  100% { background: transparent; box-shadow: none; }
}
```

**额外细节**:`.cid-anchor` 默认有 `top: -56px`,抵消顶部 toolbar 高度,确保 scrollIntoView 后内容正好显示在可见区域。

### 4. 触发源(谁派发 jump-to-chunk)

| 来源 | 事件 |
|---|---|
| 全文/语义搜索结果点击 | `search-results.ts` 点卡片 → `onNoteOpen(path, idx)` → `main.ts` 派发 |
| chat 引用卡片点击 | `chat-panel.ts` 点 `KB#1` 卡片 → 派发 `open-citation` → `main.ts` 派发 `ll-jump-to-chunk` |

两者最终都通过 `main.ts.handleSelectDirect(path, idx?)` 统一处理。

## 📊 数据

- 包大小:+1 KB(纯渲染逻辑)
- 渲染开销:每篇笔记额外插 N 个 `<a>` 锚点(N = chunks 数,典型 5-20),可忽略

---

## ⚠️ 升级注意

- **零破坏性** — `parseNote(content)` 老调用照常工作(不传 opts 就跳过锚点注入)
- **chunk 必须已索引** — 若笔记还没 chunks(刚 sync 完还没跑 chunker),点击不会跳转(有 console.warn 提示)
- **路径不匹配时静默忽略** — 避免误触发
