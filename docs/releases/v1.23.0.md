## 🐛 修复的 3 个用户报告问题

### Fix A: EPUB 检索为空
**现象**:Agent 跑 5 步,`kb_search` 返回空,LLM 拿不到内容
**根因**:`lib/agent.ts` 的 `kb_searchTool.execute` 强制传 `includeLocal = false`,而本地 EPUB 路径是 `📘 xxx.epub` —— `search.ts` 默认过滤掉 `📘` 前缀
**修复**:Agent 路径默认 `includeLocal = true`(只在 ctx 显式传 false 才过滤)
**影响**:Agent 现在能检索到本地 PDF / EPUB 索引的 chunks

### Fix B: PDF 索引不完整
**现象**:大 PDF 索引不到全部内容
**根因**:
- 渲染只显示前 5 页(用户感知),但**索引函数是遍历所有页的**
- 实际 bug:webview 长 await 阻塞 + 大 PDF 索引中途崩溃但静默失败
**修复**:
- `indexLocalPdf` 改分批(每批 10 页 + setTimeout 让 webview 喘息)
- 加 `PDF_INDEX_MAX_PAGES = 999`(不再硬限 5 页)
- 加 `emptyPages` 计数 + 扫描版警告(>50% 空页 → 提示"需要 OCR")
- 加 page.cleanup() 释放 webview 内存

### Fix C: Agent 没有上下文记忆
**现象**:用户感觉 Agent 不认识"我是谁"
**根因**:`runAgentReAct` 只用当前 messages,**不读长期记忆**;非 agent 路径也一样
**修复**:
- Agent 路径(`runAgentReAct`)开头注入 `buildMemoryPrompt()` 到 system prompt
- 非 agent 路径(简单 chat)同样注入
- 效果:LLM 自动看到"用户偏好 X" / "用户事实 Y" / 跨 session 的所有记忆
