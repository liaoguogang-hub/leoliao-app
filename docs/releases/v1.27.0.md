# v1.27.0 — 严格 RAG:严禁幻觉

> **代号**: `strict-rag` · 2026-09-04

## 🐛 问题

Agent 之前 fallback 时 prompt 让 LLM "直接回答用户问题" → LLM 用训练知识编出生命 3.0 各章概要,虽然承认"坦白",但仍给了看似有内容的列表。

## ✅ 修复

### `lib/search.ts` 两个 prompt 改成"严禁幻觉"

**之前**:`kbResults.length === 0` 时 prompt 完全去掉 KB context,让 LLM"直接回答"

**现在**:prompt **明确禁止**用训练知识,KB 没找到就告诉用户没找到

```ts
// buildRAGPrompt + buildFullRAGPrompt 都加:
"你是 LeoLiao 知识库助手。**严禁**用自己的训练知识回答。
如果知识库内未找到相关内容,**必须**直接告诉用户:
'知识库内未找到相关信息,请把相关材料放进 vault 后再问。'"
```

### 结构性问题的强化规则

```ts
"如果用户问'每章主要内容'等结构化问题,
 只回答检索到内容的章节,其他章节明确标'KB 无原文'"
```
