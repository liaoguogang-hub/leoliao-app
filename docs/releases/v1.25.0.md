# v1.25.0 — UX: 本地索引重做 + includeLocal 默认开

> **代号**: `local-index-ux` · 2026-09-04

## ✨ 新增

### 1. 本地文件一键重索引

`local-files-panel.ts` 加 `🔄 重索引全部` 按钮:
- 黄色提示框:"⚠️ 索引不完整?"
- 确认后从 `history` 表拿所有本地 PDF/EPUB
- 删旧 chunks/vectors/notes → 重新抽取文字 → 写回 IndexedDB
- 实时进度:`⏳ 3 / 5 - 重建 xxx.pdf`

### 2. includeLocal 默认开启

之前 `includeLocal=false`,用户必须手动勾。**v1.25 默认 true**:
- 新用户装上就能搜本地
- 老用户用 localStorage 持久化(`ll-chat-include-local`)

### 3. UI 状态可视化

复选框右边加状态徽章:
- `✓ 已启用`(绿色)
- `⚠ 关闭中 — 不会搜本地 PDF/EPUB`(黄色)
