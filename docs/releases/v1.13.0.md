# v1.13.0 — Phase R.2: 侧栏三 Tab 搜索 UI

> **发布日期**: 2026-09-04
> **代号**: Phase R.2 / search-tabs
> **类型**: 用户体验升级(向后兼容)

---

## 🎯 主题

把侧栏搜索从"单一路径匹配"升级为**三 Tab 模式**:
- 📂 **路径**:文件名/路径子串匹配(原行为,最快)
- 📖 **全文**:BM25 over chunk.content(找到具体段落)
- 🧠 **语义**:BM25 + 向量 + RRF(支持自然语言问句)

外加 Cmd/Ctrl+K 快捷键聚焦搜索框。

---

## ✨ 新增

### 1. 三 Tab 切换

```
┌─────────────────────────────────────────────┐
│  🔍 [输入框 placeholder 根据 tab 切换]       │
├─────────────────────────────────────────────┤
│  [📂 路径]  [📖 全文]  [🧠 语义]            │
├─────────────────────────────────────────────┤
│  ☑ 🎯 Rerank (全文/语义 Tab 时显示)        │
├─────────────────────────────────────────────┤
│  [结果区]                                    │
│  - 路径模式:文件树(原行为)                   │
│  - 全文/语义模式:结果卡片列表                 │
└─────────────────────────────────────────────┘
```

### 2. `ll-search-results` 新组件

`src/components/search-results.ts` — 全文/语义模式专用结果列表。

**结果卡片布局**:
```
┌──────────────────────────────────────┐
│ #1  [笔记标题]              [0.873]  │
│ 📌 [heading 名]                      │
│ 这是 snippet,query token 会被       │
│ <mark>高亮</mark>,便于快速定位       │
│ 📂 [完整路径]                        │
└──────────────────────────────────────┘
```

**特性**:
- snippet 内 query token 高亮(黄底 + 粗体)
- score 显示在右上角(归一化到 0-1)
- 点击卡片 → `onNoteOpen(path)` → 父组件打开笔记
- 三种状态:加载中(spinner)/ 空态(提示)/ 有结果

### 3. 200ms 防抖全文/语义检索

```ts
scheduleSemanticSearch(q: string) {
  // 防抖:连续输入时只触发最后一次
  clearTimeout(this.semanticDebounce);
  this.semanticDebounce = setTimeout(async () => {
    const mode = tab === 'fulltext' ? 'bm25' : 'hybrid';
    this.semanticResults = await search(q, 30, 12000, [], mode, false, rerankOpts);
  }, 200);
}
```

### 4. Cmd/Ctrl + K 快捷键

按 Cmd+K(Mac)或 Ctrl+K(Windows / Linux):
- 自动打开侧栏
- 自动聚焦搜索框
- 自动选中已有内容(便于覆盖输入)

### 5. UI 偏好持久化

localStorage key `ll-sidebar-ui`:
```json
{
  "sidebarTab": "fulltext",
  "useRerank": true
}
```

下次打开恢复上次 Tab + Rerank 状态。
