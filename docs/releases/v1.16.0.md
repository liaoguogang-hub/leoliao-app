## ✨ 新增

### 1. `src/services/wiki-auto.ts` — 自动 Wiki 生成引擎

**入口**: `generateAutoWiki({ prefix, maxConcepts, maxMocs, maxTimeline })`

**输出结构**:
```ts
interface AutoWiki {
  scope: string;                    // 范围
  noteCount: number;                // 笔记数
  totalSize: number;                // 总大小
  overview: string;                 // 100 字概览
  concepts: AutoWikiConcept[];      // 关键概念 Top10
  mocs: AutoWikiMoc[];              // MOC 按 tag 聚合
  timeline: AutoWikiTimelineEntry[]; // 时间线
  generatedAt: number;
  source: 'llm' | 'stats';          // 当前仅 stats
  durationMs: number;
}
```

**实现**:
- **概览**:统计拼接(笔记数 / 总大小 / 平均字/篇 / 子目录数)
- **关键概念**:frontmatter tags(权重 ×2) + 标题 token 频次(权重 ×1)
- **MOC**:`tagIndex()` 按 tag 分组,每个 tag 下展开路径
- **时间线**:`recentNotes(15)` 按 mtime 倒序

### 2. wiki-panel 加 Tab 切换

```
[📊 总览]  [✨ 自动 Wiki]
```

### 3. 自动 Wiki UI

- 输入框:文件夹前缀(留空=整个 vault)
- 生成按钮 → 显示结果
- 结果包含:`badge`(笔记数/KB/耗时/来源)+ 概览框 + 概念 chips + MOC 折叠列表 + 时间线
- 每条 MOC 路径可点击 → 派发 `open-note` 事件 → 父组件打开笔记
- 每条时间线可点击 → 打开笔记

### 4. `renderAutoWikiAsMarkdown` — 一键导出

```ts
export function renderAutoWikiAsMarkdown(wiki: AutoWiki): string;
// → "# scope Wiki\n\n> 自动生成...\n\n## 📌 概览\n..."
```

`💾 保存为 .md` 按钮 → 复用 `export-service.saveToLocal` 让用户选位置保存。

### 5. 性能

- L2 统计模式 ~50ms(vault 1000+ 笔记)
- L1 LLM 模式预留接口(`source: 'llm'`),后续版本接入 chat settings 的 LLM
